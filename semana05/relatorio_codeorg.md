# Relatório Code.org

Consegui terminar os desafios das lições 10 a 14! O mais legal dessa etapa é que agora o projeto realmente virou um jogo. Aprendi a usar o teclado e o mouse para controlar os personagens, coloquei velocidade automática neles e aprendi a fazer os objetos baterem uns nos outros. 

Para fazer os controles funcionarem, o código usa a regra das "Condicionais". Funciona assim:

    Controles: Eu coloco um bloco no código que diz para o computador: "SE o jogador apertar a setinha pro lado direito, mude a velocidade do personagem para a direita".

    Colisões: O código fica o tempo todo checando a tela. Eu coloco uma condição perguntando: "o personagem encostou na parede?". SE a resposta for sim, eu dou uma ordem para ele parar de andar ou quicar para o outro lado.

Entender como o computador detecta os cliques do mouse e as teclas apertadas faz a gente perceber como os jogos são controlados de verdade.
